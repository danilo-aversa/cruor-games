# Bestiary Weighting Methodology

## Source

`Bestiary.csv`, 503 Monster Manual 2025 creatures.

## Method

The analysis classified authored trait, action, bonus-action, reaction, legendary, mythic, lair, and regional entries using rule-text indicators. The resulting prevalence values were then manually mapped to Cruor's nine graft families.

The analysis is intentionally conservative:

- a normal attack is distinct from an Attack Pattern;
- movement printed only in the Speed line is not counted as a special Movement system;
- rarity does not automatically increase weight;
- activation window and simultaneity modify the editorial interpretation;
- the final score still comes from each graft's compiled ability model, with the family prior applied afterward.

## Limits

The corpus does not label Cruor graft families directly. The percentages are therefore proxy classifications rather than claims that official monsters contain Cruor components. They are used to calibrate relative expectations across the catalog, not to replace individual mechanical review.
