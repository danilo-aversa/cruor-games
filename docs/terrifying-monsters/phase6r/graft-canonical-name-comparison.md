# Terrifying Monsters — Canonical Name Comparison

## Decision

`Bestiary.csv` is authoritative for recognizable D&D feature and action names, but the naming policy distinguishes between a parent Attack Pattern and the actions it contains.

- **Body and Movement:** preserve an exact Bestiary feature name when the Graft remains recognizably that feature.
- **Attack Pattern:** use an evocative parent name in the Composer; preserve canonical or descriptive action names inside the pattern and in the stat block.
- **Mind:** use short behavioral names unless a direct canonical feature correspondence exists.

## Exact Bestiary matches preserved

- Cunning Action;
- Ethereal Sight;
- Incorporeal Movement;
- Spider Climb;
- Vanish;
- Web Walker.

`Stumbling Mass` remains approved by explicit editorial direction even though it is not an exact CSV match.

## Attack Pattern examples

| Pattern title | Ability names retained |
|---|---|
| Crusher | Heavy Slam, Corpse Grab |
| Acid Brute | Heavy Slam, Acid Vomit |
| Venom Hunter | Venomous Bite, Venomous Spit, Web |
| Web Hunter | Venomous Bite, Web |
| Cold Touch | Cold Funeral Touch |

This preserves immediate D&D readability in the generated stat block while giving the Composer a stronger, more evocative identity label.
