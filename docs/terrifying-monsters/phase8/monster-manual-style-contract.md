# Phase 8 — Monster Manual Style Contract

The style review is calibrated against 503 MM'25 monsters in `Bestiary.csv`.

Cruor grafts are intentionally more procedural than ordinary bestiary entries because each graft must remain reusable across many generated monsters. Even so:

- the rendered rule must lead with trigger, resolution, target, and outcome;
- counterplay belongs in the rule only when it changes adjudication;
- repeated explanations and duplicated procedure text are removed;
- one rendered ability may not exceed 90 words;
- text above 75 words requires an explicit editorial rationale;
- evocative parent names must not replace canonical action terminology inside the stat block;
- every clause represented in simulation must remain visible in rendered output.
