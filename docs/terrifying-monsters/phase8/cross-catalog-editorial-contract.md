# Phase 8 — Cross-Catalog Editorial Contract

The ninety-three published grafts are reviewed as one game-design catalog rather than nine isolated slot families.

The gate requires:

- no two Attack Patterns compile to the same mechanical bundle at CR 5 or CR 15;
- shared base actions may recur only when the parent routines and signature actions remain distinct;
- cost and declared complexity must reflect the authored decision load;
- public graft IDs remain stable;
- overlapping chassis or infrastructure features must expose a compatibility warning instead of silently stacking;
- source identity remains visible without making any source mechanically mandatory.

This pass does not remove deliberate source synergies. It prevents accidental equivalence, hidden dominance, and tracking overload.
